# Figure Code

Each figure should live in its own subdirectory with:

- one script per panel;
- a short README explaining required input files;
- a stable output filename for the manuscript panel.

Example:

```text
fig4_g4_secondary_structure/
  make_fig4a_mfe_boxplot.py
  make_fig4b_signal_heatmap.py
  make_fig4c_structure_disruption.py
  README.md
```
